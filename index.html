VS Code da Kod Yozish

Noldan professional darajaga — oddiy va tushunarli

1 VS Code nima va qanday o‘rnatiladi?

Visual Studio Code (VS Code) — Microsoft tomonidan yaratilgan, bepul va eng mashhur kod yozish dasturi. U Python, JavaScript, HTML, CSS, C++, Java va boshqa deyarli barcha tillarni qo‘llab-quvvatlaydi.

Maslahat: Rasmiy saytdan yuklab ol: code.visualstudio.com

O‘rnatish qadamlari:

  1. Saytga kirib, “Download” tugmasini bosing
  2. Windows / Mac / Linux versiyasini tanlang
  3. Yuklangan faylni ochib, “Next → Next → Install” bosing
  4. O‘rnatib bo‘lgach, VS Code ni ishga tushiring

2 Interfeysni tushunish

VS Code ochilganda quyidagi asosiy qismlarni ko‘rasiz:

  • Explorer (chap tomonda) — fayllar va papkalar
  • Editor (o‘rtada) — kod yoziladigan joy
  • Terminal (pastda) — buyruqlar yoziladi
  • Extensions — qo‘shimcha dasturlar (plaginlar)
Terminalni ochish: Ctrl + ` (backtick tugmasi)

3 Birinchi faylni yaratish

Keling, oddiy HTML fayl yaratamiz:

  1. VS Code da File → Open Folder bosing
  2. Yangi papka yarating (masalan: mening-saytim)
  3. Chap tomonda Explorer da o‘ng tugma → New File
  4. Fayl nomini index.html deb yozing
<!DOCTYPE html> <html> <head> <title>Mening birinchi sahifam</title> </head> <body> <h1>Salom, dunyo!</h1> <p>Men VS Code da kod yozishni o‘rganmoqdaman.</p> </body> </html>
Faylni saqlash: Ctrl + S

4 Eng muhim qisqa tugmalar (Shortcuts)

Ctrl + S → Faylni saqlash Ctrl + ` → Terminalni ochish/yopish Ctrl + B → Chap panelni yashirish/ko‘rsatish Ctrl + P → Tezkor fayl qidirish Ctrl + Shift + P → Barcha buyruqlar Ctrl + / → Kodni kommentga olish Alt + ↑ / ↓ → Qatorni yuqoriga/pastga ko‘chirish Ctrl + D → Bir xil so‘zlarni tanlash
Eslatma: Mac da Ctrl o‘rniga Cmd ishlatiladi.

5 Muhim Extensions (Plaginlar)

VS Code kuchliroq bo‘lishi uchun quyidagi plaginlarni o‘rnating:

  • Live Server — HTML sahifani real vaqtda ko‘rish
  • Prettier — kodni avtomatik chiroyli qilish
  • Python — Python uchun
  • ESLint — JavaScript xatolarini topish
  • Auto Rename Tag — HTML teglarini avtomatik o‘zgartirish
  • Material Icon Theme — chiroyli ikonkalar
Extensions ochish: chap tomondagi to‘rtburchak ikonka yoki Ctrl + Shift + X

6 Live Server bilan ishlash

Live Server o‘rnatganingizdan keyin:

  1. index.html faylini oching
  2. O‘ng pastki burchakda Go Live tugmasini bosing
  3. Brauzer avtomatik ochiladi
  4. Kodni o‘zgartirsangiz, sahifa avtomatik yangilanadi
Bu eng qulay usul — har saqlaganda sahifa yangilanadi!

7 Keyingi qadamlar

Endi siz asoslarni bildingiz. Keyingi bosqichlar:

  • HTML + CSS o‘rganish
  • JavaScript o‘rganish
  • Git va GitHub bilan ishlash
  • Python yoki boshqa til tanlash
